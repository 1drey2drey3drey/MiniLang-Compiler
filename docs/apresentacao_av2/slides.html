O MiniLang-Compiler une os 3 níveis da Hierarquia de Chomsky num único fluxo.

1program matricula {
2 if ((ativo)) { }
3 func matricular(int, string, int);
4 matricular(101, "ana", 2026);
5}
O que o compilador verifica nesse código3 camadas
  • 1. Léxico (ER · AV1): reconhece palavras e símbolos válidos do alfabeto.
  • 2. Sintaxe (AP · Etapa 1): garante que blocos { } e ( ) abrem e fecham certo.
  • 3. Semântica (ALL · Etapa 2): garante que func(int, string, int) bate com (101, "ana", 2026).

Camada 1 (AV1) · Expressões Regulares03 / 14

No MiniLang-Compiler, as ERs leem o código-fonte e filtram o alfabeto.

O que é ER no nosso compilador?Tipo 3 · Regular
  • Definição: padrão formal sem pilha nem fita, executado pelo MiniLexer (AFNε de Thompson).
  • Papel no fluxo: transforma o texto programa.min em tokens e projeta 1:1 para o alfabeto Σ_AP.
  • Barreira léxica: bloqueia caracteres estranhos (como @ ou $) antes dos autômatos.
  • Limitação: ER não tem memória para contar profundidade de { } e ( ).

Fundamentação Formal · Hierarquia de Chomsky05 / 14

ER não conta profundidade; pilha (LIFO) não compara tipos na mesma ordem.

Por que L₁ exige AP?L₁ ∈ LLC \ LR
p{( ( ( ) ) )}#i:i;
Bombear y=(( → p{((((())))}#i:i; ✗
  • Pelo Lema do Bombeamento Regular, |xy| ≤ p prende y no início.
  • Repetir y duplica p, { ou cria mais ( que ).
  • Conclusão: AFD/ER não resolve → precisa de AP.
Por que L₂ = w:w exige ALL?L₂ ∈ LSC \ LLC
Pilha (LIFO) inverte ✗ i s → sai s i
Fita (ALL) mesma ordem ✓ i s : i s
iiss:iiss → bombear cruzando : → iisss:iiiss ✗
  • Pelo Lema do Bombeamento LLC, |vwx| ≤ p não alcança blocos iguais nos dois lados.
  • Conclusão: AP não resolve → precisa de ALL.

Camada 2 (AV2 · Etapa 1) · Autômato de Pilha06 / 14

No MiniLang-Compiler, o AP usa uma pilha LIFO para validar escopos e estrutura.

O que é o AP no nosso compilador?Tipo 2 · DPDA
  • Definição: autômato finito + pilha ilimitada (o último símbolo que entra é o primeiro que sai).
  • Papel aqui (MiniParser): valida a sintaxe p{α}#w:u; com aninhamento arbitrário de { } e ( ).
  • Regra de ouro: abriu bloco → empilha; fechou bloco → desempilha o par exato do topo.
  • Aceitação e parada: atinge q8 lendo 100% da entrada, sempre em no máximo n + 1 passos.

Camada 3 (AV2 · Etapa 2) · Autômato Linearmente Limitado10 / 14

No MiniLang-Compiler, o ALL usa fita finita para casar tipos posição a posição.

O que é o ALL no nosso compilador?Tipo 1 · D-LBA
  • Definição: Máquina de Turing cujo cabeçote vai e volta, mas fica preso entre as bordas < e >.
  • Papel aqui (MiniSemantic): recebe a fatia w:u e verifica se assinatura e chamada têm mesma aridade e ordem (w = u).
  • Estratégia in-place: marca cada par casado (i→I, s→S) sem alocar memória extra.
  • Terminação garantida: marcação irreversível ⇒ no máximo n/2 ciclos ⇒ O(n²).
