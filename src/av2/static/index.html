            01 :: chomsky_hierarchy
            

              
[Tipo 3 · AV1]  MiniLexer     ER + AFNε de Thompson     → tokenização e erros léxicos (135 testes)
[Tipo 2 · AV2]  MiniParser    GLC LL(1) + AP (9 est.)   → escopos {...} e expressões (...) balanceados
[Tipo 1 · AV2]  MiniSemantic  LSC + ALL (11 est.)       → aridade e ordem posicional w:w em fita limitada

            

          


          

            02 :: minilang_to_formal_map
            

              
program nome  → p     { ... }      → { }     ( ... )        → ( )
fn f(...)     → #     int / 10     → i       string / "ok"  → s
f(...)        → :     ;            → ;       bordas ALL     → < ... >

Nota: o modo 'minilang' faz apenas projeção mecânica via MiniLexer (AV1),
sem checar balanceamento nem igualdade de tipos. 100% da decisão ocorre em
δ_AP e δ_ALL (testável diretamente sem front-end no modo 'raw').

            

          


          

            03 :: pumping_lemma_proofs
            

              
L₁ ∉ Regular (z = p{(ᵖ)ᵖ}#i:i;):
  |xy| ≤ p ⇒ y ⊆ p{(ᵖ⁻² ⇒ xy²z duplica 'p' ou desbalanceia '{'/'('. Contradição.

L₂ ∉ LLC (z = iᵖsᵖ:iᵖsᵖ):
  |vwx| ≤ p ⇒ se fica de um lado quebra tamanho; se cruza ':' só atinge sᵖ à esq. e iᵖ à dir.
  Logo uv²wx²y não pode preservar w = u. Como há D-LBA em espaço n+2, L₂ ∈ LSC \ LLC.

            

          


          

            04 :: determinism_halting_and_tape_bounds
            

              
Determinismo : 0 estados não-determinísticos (confirmado pelo JFLAP 7.1 PDANondeterminismDetector).
Parada AP    : toda transição consome 1 símbolo, exceto (q2, ε, Z) → (q3, Z) (1x) ⇒ ≤ n + 1 passos O(n).
Parada ALL   : cada ciclo marca irreversivelmente 1 par {i,s} → {I,S} ⇒ ≤ ⌊n/2⌋ ciclos ⇒ O(n²).
Bordas ALL   : apenas (q0,<) move R e apenas (q9,>) move L; nunca sobrescreve nem cruza bordas.
