2. Fundamentação Formal

Classificação na Hierarquia de Chomsky

Etapa 1: L₁ ∈ LLC \ LR

L₁ = { p{α}#w:u; | α ∈ D₂*, w,u ∈ {i,s}⁺ }

  • Prova (Bombeamento Regular): para z = p{(ᵖ)ᵖ}#i:i;, qualquer fator y com |xy| ≤ p cai em p{(ᵖ⁻².
  • Bombear xy²z duplica p, desequilibra { ou cria mais ( do que ) ⇒ xy²z ∉ L₁.

Etapa 2: L₂ ∈ LSC \ LLC

L₂ = { w:w | w ∈ {i,s}⁺ }

  • Prova (Bombeamento LLC): para z = iᵖsᵖ:iᵖsᵖ, com |vwx| ≤ p:
  • Se vwx fica de um lado só, quebra o tamanho; se cruza :, só atinge sᵖ à esq. e iᵖ à dir., quebrando igualdade posicional.
  • Reconhecida em fita linearmente limitada ⇒ LSC.
Referências: Sipser (2013), Hopcroft et al. (2007), Aho et al. (2006)Slide 3 / 11

GLC LL(1) e Derivação Passo a Passo

Produções de G = (V, T, P, S)

V = { S, B, T, R }
T = { p, {, }, (, ), #, i, s, :, ; }

P1: S → p{ B }# T : T ;
P2: B → { B } B
P3: B → ( B ) B
P4: B → ε
P5: T → i R      P6: T → s R

4. Etapa 1 — Autômato de Pilha Determinístico

AP (MiniParser): 9 Estados e Relação com a GLC

Especificação da 7-tupla

  • Estados (9 ≥ 8): q0..q8, inicial q0, final F = {q8}.
  • Pilha: Γ = {Z, {, (}, topo inicial Z.
  • Aceitação: estado final q8 + consumo integral da entrada.
  • Determinismo: 0 estados não-determinísticos (validado pelo JFLAP 7.1).
  • Terminação: no máximo n + 1 passos (O(n)).

Fluxo dos Estados

q0 --p--> q1 --{ / push {--> q2 (empilha {,( / desempilha },))
q2 --ε, Z / Z--> q3 (escopo principal fechado)
q3 --#--> q4 --i|s--> q5 (assinatura {i,s}⁺)
q5 --:--> q6 --i|s--> q7 (chamada {i,s}⁺)
q7 --;--> q8 (ACEITA)

A pilha acima de Z em q2 mantém exatamente os blocos abertos de B, garantindo L(M_AP) = L(G).

5. Etapa 2 — Autômato Linearmente Limitado

ALL (MiniSemantic): 11 Estados em Fita Limitada

Modelo de Fita Estritamente Limitada

  • Estados (11 ≥ 8): q0..q10, final F = {q10}.
  • Alfabetos: Σ = {i, s, :}; Γ = {<, >, i, s, :, I, S}.
  • Memória: exatamente n células graváveis (1..n) + 2 bordas fixas < (pos 0) e > (pos n+1).
  • Segurança de borda: < só move R (em q0), > só move L (em q9). Jamais sobrescreve ou cruza bordas.

Algoritmo In-Place (Casamento Posicional)

  1. q0→q1: entra pela borda < e exige assinatura não vazia.
  2. q1/q8: marca próximo símbolo à esq. (i→I vai para q2; s→S vai para q3).
  3. q2/q3→q4/q5: cruza :, pula I/S e exige o mesmo tipo à direita.
  4. q6→q7→q8: volta até a fronteira marcada e repete.
  5. q8→q9→q10: ao ver :, varre sobras até > e aceita em q10.

Terminação: marcação irreversível em cada ciclo ⇒ O(n²).

8. Análise Crítica

Limitações Observadas nos Testes

1. Tempo O(n²) em Fita Única

O movimento ida-e-volta do cabeçote faz o número de passos crescer quadraticamente (ex.: 19 chars → 201 passos no ALL).

2. Subconjunto de 2 Tipos

Modelamos i e s para manter 11 estados didáticos; adicionar float/bool/time exigiria +2 estados de transporte/casamento por tipo.

3. Assinatura Única

Valida uma assinatura e uma chamada por cadeia formal; múltiplas declarações demandariam identificadores e memória auxiliar na fita.
